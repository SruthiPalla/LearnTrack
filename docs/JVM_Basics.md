# JVM Basics

## What is JDK?

JDK (Java Development Kit) is a software package used to develop Java applications. It contains the Java compiler (javac), Java Runtime Environment (JRE), and development tools.

---

## What is JRE?

JRE (Java Runtime Environment) provides the environment required to run Java applications. It includes the JVM and Java libraries.

---

## What is JVM?

JVM (Java Virtual Machine) is responsible for executing Java bytecode. It converts bytecode into machine code so that the operating system can execute it.

---

## What is Bytecode?

When Java source code (.java) is compiled, it becomes bytecode (.class).

The JVM reads this bytecode and executes it.

---

## Write Once, Run Anywhere

Java follows the principle "Write Once, Run Anywhere."

A Java program is compiled only once into bytecode.

Since every operating system has its own JVM, the same bytecode can run on Windows, Linux, or macOS without changing the source code.
